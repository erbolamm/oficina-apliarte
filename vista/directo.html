Lanzador por Sistema Operativo

Selecciona tu entorno de trabajo para arrancar o consultar las instrucciones de ejecución.

Servidor anfitrión: Detectando anfitrión… Guarda en backend activa (Lección 71)
Arranque nativo en este Mac

Ejecuta el ciclo de inicio directamente a través de la API de la Oficina local.

Comando CLI unificado 
dart run bin/trabajo.dart erbolamm directo on
Comando directo en el repositorio 
cd ~/repos/apliarte-directo && npm run directo
Arranque en nodo PC (Windows)

Ejecuta el servicio de directo en el nodo Windows si este servidor es el anfitrión.

PowerShell (Recomendado) 
Set-Location "$env:USERPROFILE\repos\apliarte-directo"; npm run directo
Símbolo del sistema (CMD / Batch) 
cd %USERPROFILE%\repos\apliarte-directo && npm run directo

Requisitos: Node.js 20 o superior y dependencias instaladas en el repositorio (npm install). Rama segura: feat/windows-soporte-directo (commit ec210f9).

Arranque en nodo Linux / VPS

Ejecuta el servicio de directo en el entorno Linux si este servidor es el anfitrión.

Terminal interactiva (SSH) 
cd ~/repos/apliarte-directo && npm run directo
Segundo plano con nohup 
cd ~/repos/apliarte-directo && nohup npm run directo > directo.log 2>&1 &

Puertos en cortafuegos: 7979/tcp (Estudio HTTP), 8790/tcp (Centro API), 1935/tcp (Ingesta RTMP).
